# Дизайн Aura: Dark Glassmorphism (v2)

Стиль — тёмный графит и **полупрозрачные пузыри** в духе Apple: тонкая светлая
рамка, блик по верхнему краю, размытие фона, акцент — мягкий фиолет `#7C6AFF`.
Интерфейс остаётся серым; акцент используется точечно.

Единый источник токенов — `client/qml/theme/AuraTheme.qml` (QML-синглтон).
`preview/styles.css` и `client/styles/aura_theme.qss` повторяют те же значения.
Правьте палитру во всех трёх файлах сразу.

Шрифт: Inter → SF Pro Text → Segoe UI → Noto Sans.
Размеры: 11 (micro), 12 (small), 14 (body), 18 (title), 28 (hero).

## Как собрано стекло

**QML** (`GlassSurface.qml`): `ShaderEffectSource` вырезает область под панелью,
`MultiEffect` размывает и обрезает маской со скруглениями, сверху — плёнка
`rgba(255,255,255,.04)` с рамкой 1 px и градиентным бликом.

**CSS** (`preview/styles.css`): одной строкой —
`background: rgba(255,255,255,.04)`, `backdrop-filter: blur(24px)`,
`border: 1px solid rgba(255,255,255,.08)`,
`box-shadow: 0 8px 32px rgba(0,0,0,.35), inset 0 1px 0 rgba(255,255,255,.10)`.

**Qt Widgets** (`aura_theme.qss`): backdrop-filter нет, поэтому стекло
имитируется полупрозрачной плёнкой + `QGraphicsBlurEffect`.

## Кнопки

* форма — радиус 22 (пилюля для CTA), высота 44 px;
* варианты: glass (нейтральное стекло), accent (сплошной `#7C6AFF` + свечение),
  quiet, danger;
* hover: подъём на 1 px + подсветка; pressed: `scale(0.97)`;
* `busy`: глиф гаснет, крутится кольцо; `disabled`: непрозрачность 0.45.

## Сообщения

* чужие — слева, нейтральное стекло;
* свои — справа, акцентное стекло `rgba(124,106,255,.16)`;
* от Ауры — слева, фиолетовое стекло + свечение + значок «Аура»;
* подпись под пузырём: имя и время, `text-tertiary`.

## Фон

`radial-gradient(ellipse at 30% 20%, #1a1a2e, #0d0d0f 70%)` + шум 2% и два
размытых пятна `#5B4DD6`/`#3B4DD6`, которые медленно дрейфуют — они видны
сквозь стекло.

## Экраны (концепт, см. `preview/`)

Login, Register, Home (дашборд), My Aura (чат), Negotiations (таймлайн A2A),
Tasks, Contacts, Settings. У всех — общий левый сайдбар и одни токены.

## Адаптивность (этап 12)

Окно desktop-клиента живёт в двух раскладках; переключение — по ширине окна,
мгновенно при ресайзе (Loader в `Main.qml`), выбранный чат сохраняется.

| раскладка | условие | навигация |
| --- | --- | --- |
| компактная | ширина < `breakpointWide` (1120) | стек: ChatsPage → ChatPage / SettingsPage (кнопка «назад») |
| desktop | ширина ≥ 1120 | `DesktopShell`: рельс 76px (Чаты / Задачи / Ждут / Ещё) + контент |

* Чаты в desktop-раскладке — master-detail: колонка списка `masterWidth`
  (340px) слева, диалог справа; выбранный чат подсвечивается акцентом.
* Список чатов вынесен в `components/ChatList.qml` — один компонент на обе
  раскладки (в стеке `selectedChatId = -1`, подсветка выключена).
* Бейдж неподтверждённых операций на рельсе (жёлтый, счётчик) — барьер
  подтверждения виден из любого раздела.
* Геометрия окна (x/y/ширина/высота) запоминается между запусками
  (`QtCore.Settings`); минимум 420×640.
* Страницы знают про встройку: `ChatPage.embedded` / `SettingsPage.embedded`
  прячут кнопки «назад»/«настройки» — в оболочке навигация через рельс.

## Доступность

* Контраст `text-primary` на `bg-base` ≈ 14:1, `text-secondary` ≈ 6.5:1.
* Все интерактивные элементы имеют hover/pressed/focus с клавиатуры.
* Анимации 200–300 мс и не несут смысла сами по себе: состояние дублируется
  цветом и подписью.
